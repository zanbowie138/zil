# data.charts

sparklines, bar charts, histograms and braille function plots, as text

> Example results generated on 2026-10-07.
> Ones using `now`, `today` or randomness will differ when you run them.

## Functions

| function | description |
|---|---|
| [`sparkline(xs: list)`](#sparkline) | a one-line chart: one block character per number, scaled min to max |
| [`bars(m: map\|list, width?: int)`](#bars) | a horizontal bar chart of a map (labels → numbers) or a list; width defaults to 40 |
| [`histogram(xs: list, bins?: int)`](#histogram) | count numbers into equal-width bins (default 10) and draw them as bars |
| [`plot(f: fn, a: num, b: num)`](#plot) | plot f from a to b in braille dots, 60 columns by 16 rows |

### sparkline

`sparkline(xs: list)`: a one-line chart: one block character per number, scaled min to max

```zil
[1, 5, 2, 8, 3].sparkline
# → "▁▅▂█▃"
(0..20).map(|x| sin(x / 3)).sparkline
# → "▅▆▇▇███▇▆▅▄▃▂▁▁▁▂▂▄▅"
```

See also: [bars](../data/charts.md#bars), [plot](../data/charts.md#plot)

### bars

`bars(m: map|list, width?: int)`: a horizontal bar chart of a map (labels → numbers) or a list; width defaults to 40

```zil
bars({a: 3, b: 7, c: 5})
# → "a │█████████████████▏ 3\nb │████████████████████████████████████████ 7\nc │████████████████████████████▋ 5"
[2, 4, 8].bars(16)
# → "0 │████ 2\n1 │████████ 4\n2 │████████████████ 8"
```

See also: [histogram](../data/charts.md#histogram), [sparkline](../data/charts.md#sparkline)

### histogram

`histogram(xs: list, bins?: int)`: count numbers into equal-width bins (default 10) and draw them as bars

```zil
[1, 2, 2, 3, 3, 3, 4, 4, 5].histogram(5)
# → "  1–1.8 │█████████████▍ 1\n1.8–2.6 │██████████████████████████▋ 2\n2.6–3.4 │████████████████████████████████████████ 3\n3.4–4.2 │██████████████████████████▋ 2\n  4.2–5 │█████████████▍ 1"
```

See also: [bars](../data/charts.md#bars), [count_by](../data/lists.md#count_by)
