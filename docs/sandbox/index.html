The basics

  • x.f(y) is f(x, y), and "hi".upper needs no parens
  • |x| x * 2 is a function; xs |> sum pipes
  • to converts: 5 km to mi, 255 to hex
  • help("text") lists a module; help(upper) explains a function
  • tip() suggests something to try
